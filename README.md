## 🌟 Overview

**Gen AI Hub** is a full-stack AI-powered web application designed to provide intelligent content generation and resume analysis.  
The platform integrates modern authentication, cloud services, and generative AI models to deliver real-world, production-ready features.

This project focuses on **practical AI usage**, **secure backend architecture**, and **scalable deployment**.

---

## ✨ Key Features

### 🧠 AI Capabilities
- **AI Resume Review**
  - Upload PDF resumes
  - Get ATS score, strengths, weaknesses, and improvement suggestions
- **AI Article Generator**
- **AI Blog Title Generator**
- **AI Image Generation**
- **Image Background & Object Removal**

### 🔐 Authentication & Access
- Secure user authentication using **Clerk**
- Feature access based on **subscription plan**
- Usage limits for free users

### ☁️ Cloud & Storage
- Image hosting and transformations via **Cloudinary**
- Secure file uploads using **Multer**

### 🗄️ Backend & Database
- PostgreSQL database hosted on **NeonDB**
- Robust error handling and validation
- Production-safe database operations

## ⚙️ System Design Highlights

- Implemented **PDF parsing** using `pdf-parse` for resume analysis
- Handled **ESM & CommonJS compatibility** in Node.js
- Added **graceful fallback handling** for AI API failures
- Designed **scalable controller-based architecture**
- Ensured compliance with **database NOT NULL constraints**
- Production-ready error handling and logging
